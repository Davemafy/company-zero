# 3–5 minute demo

0:00 Thesis: Most companies start with an organization then give it work. Company Zero starts with the work and builds the organization required to deliver it.

0:20 Show operating contract: mission, quality floor, budget, latency, available tools.

0:35 Run finance. Show generated organization and 70% initial result.

1:00 Open a failed duplicate case and inspect the raw role/tool trace. Show that the evaluator reports observed evidence, not “add duplicate detector.”

1:25 Show diagnosis and competing restructures. Open one rejected/losing candidate if available. Promote the proven organization and show 70% -> 100%.

2:00 Inject operating drift without resetting the company. Show quality fall, new failure evidence, new diagnosis, second restructure, then return to 100%.

2:45 Switch to support. Show a different starting organization and a different missing capability (redaction).

3:15 Show Evidence export and institutional memory.

3:35 Show actual AO dashboard, actual total session count, and explain 2–3 meaningful AO sessions used to build/debug Company Zero.

4:10 Close: The model proposes. The runtime proves. Company Zero changes the company only when changing the company is worth it.
