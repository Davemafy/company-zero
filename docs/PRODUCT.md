# Product model

Company Zero is an operating system for outcome-defined organizations.

A user supplies an operating contract: outcome, quality floor, budget, latency ceiling, available capabilities, review rules, and a workload or evaluation adapter. Company Zero compiles an organization, operates it, records evidence, identifies structural failure, evaluates alternative organizations on the same contract, promotes only a passing alternative, and retains proven structural lessons.

## Product objects
- Mission: outcome and constitution.
- Organization: versioned roles, tools, responsibilities, and instructions.
- Run: immutable execution evidence.
- Diagnosis: evidence-grounded explanation of failure.
- Candidate: proposed structural mutation plus independently measured run.
- Promotion: governor-approved organization version.
- Lesson: durable structural memory created only after promotion.

## Product principles
1. Evidence is immutable after a run.
2. Models can propose but never award their own score.
3. Every structural mutation points to observed failures.
4. A promoted organization must satisfy the constitution.
5. Human review is a capability, not a failure of autonomy.
6. Drift challenges the existing organization; it does not silently reset it.
7. The UI and API expose the same underlying mechanism.
