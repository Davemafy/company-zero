# Icon system

Company Zero uses the visual language of **coolicons** by Kryston Schwarze for core product navigation and controls.

Source: https://github.com/krystonschwarze/coolicons
Figma source supplied by the project owner.

Core source icons adapted into the application shell:
- Navigation / House_01
- Interface / Suitcase
- Interface / Chart_Bar_Vertical_01
- Interface / Link
- Interface / Settings

Utility glyphs follow the same 24×24 / 2px rounded-stroke treatment so the application reads as one icon system.
